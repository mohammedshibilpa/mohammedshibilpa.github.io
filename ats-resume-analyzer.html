🤖 AI Resume Analyzer & Recruitment Platform

An AI-powered recruitment platform that helps job seekers optimize resumes and enables recruiters to efficiently screen and rank candidates using ATS scoring, skill matching, and AI-generated interview preparation.

GitHub Features

📌 Project Overview

The AI Resume Analyzer & Recruitment Platform is an intelligent web application designed to streamline the recruitment process for both job seekers and recruiters.

For job seekers, the platform evaluates resumes against job descriptions, calculates ATS compatibility scores, identifies missing skills, provides resume improvement suggestions, and generates AI-powered interview questions.

For recruiters, it enables bulk resume screening, automatic candidate ranking, skill gap analysis, and detailed candidate comparison, reducing manual effort and improving hiring efficiency.

🚀 Key Features

👤 Job Seeker Module

  • Upload Resume (PDF / DOCX)
  • Paste Job Description
  • ATS Score Calculation
  • Resume Quality Analysis
  • Job Description Similarity
  • Matched Skills Detection
  • Missing Skills Identification
  • Resume Improvement Suggestions
  • AI Interview Questions

👨‍💼 Recruiter Module

  • Upload Multiple Candidate Resumes
  • Candidate Ranking Dashboard

  • Skill Gap Analysis
  • Candidate Details Dashboard
  • Candidate Comparison
  • Shortlisting Support
